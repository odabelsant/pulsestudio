Contexto Vivo del Proyecto

Documentación actualizada del estado del proyecto, arquitectura y próximos pasos.

Arquitectura del Proyecto

El proyecto está construido con una pila moderna de frontend y backend local, incluyendo persistencia con Prisma y SQLite.

  • Next.js 16.2.9 con App Router y `src/`.
  • TypeScript 5 para tipado estricto.
  • Tailwind CSS v4 para estilo utilitario.
  • Prisma 7.8.0 + SQLite para almacenamiento local.
  • AI SDK con `ai` y `@ai-sdk/google`.
  • Shadcn UI para componentes reutilizables de interfaz.

Estructura de Carpetas

  • src/app/ - rutas y páginas principales.
  • src/app/(admin)/ - paneles administrativos para agentes y contexto.
  • src/components/ - UI y componentes reutilizables.
  • src/lib/ - utilidades compartidas, incluyendo Prisma.
  • src/generated/prisma/ - cliente Prisma generado.
  • prisma/ - esquema y configuración de la base de datos.
  • _context/ - memoria viva y documentación del proyecto.

Conexión de Módulos

Las páginas administran datos mediante APIs CRUD que usan Prisma para persistencia local.

  1. La UI de administración llama a `/api/agents` y `/api/context`.
  2. Las rutas API usan `src/lib/prisma.ts` para acceder a SQLite.
  3. La página principal consulta y adjunta contextos locales.
  4. El estado `attached` en `src/app/page.tsx` mantiene los documentos adjuntos seleccionados.
